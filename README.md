# VITSTORE — គេហទំព័រលក់ខោអាវ

គេហទំព័រ Static (HTML + CSS + JS សុទ្ធ) សម្រាប់ហាង **Vitstore** — ខោអាវព្យួរ អូសមើលបាន
ចុចមើលតម្លៃ និងកម្មង់តាម **Telegram** ដោយសារកម្មង់ (ឈ្មោះខោអាវ · ទំហំ · ពណ៌ · តម្លៃ) ផ្ញើចូលឆាតហាងស្រាប់។

---

## ១. របៀបបើកមើល

គ្រាន់តែបើក `index.html` ក្នុង browser ក៏បាន។ ប៉ុន្តែដើម្បីឱ្យមុខងារ «ផ្ញើរូបភាព»
(share sheet) ដំណើរការត្រឹមត្រូវ សូមបើកតាម local server៖

```bash
python3 -m http.server 4173     # រួចបើក http://localhost:4173
```

## ២. ដាក់ Telegram របស់ហាង (សំខាន់!)

មាន ២ វិធី៖

1. **លើគេហទំព័រ** — ចុច «កំណត់ Telegram» នៅ footer → ដាក់ username/លេខទូរស័ព្ទ → រក្សាទុក
   (រក្សាទុកក្នុង browser របស់អ្នកតែប៉ុណ្ណោះ)
2. **អចិន្ត្រៃយ៍ (សម្រាប់ភ្ញៀវទាំងអស់)** — កែឯកសារ `js/config.js`
   (ឯកសារនេះជា **Read-Only** — `Object.freeze` — ដូច្នេះការកែត្រូវធ្វើក្នុងកូដតែម្ដង)៖

```js
telegram: "idgafidgaf3",                        // → https://t.me/idgafidgaf3
phone: "+855967925615",                         // លេខបង្ហាញលើគេហទំព័រ
address: "កោះកែវ, ល្វាឯម, កណ្ដាល",              // ទីតាំងហាង (បង្ហាញលើ footer + ទំនាក់ទំនង)
usdToKhr: 4100,                                 // អត្រាប្ដូរប្រាក់សម្រាប់បង្ហាញតម្លៃរៀល
freeShipNote: "ដឹកជញ្ជូនឥតគិតថ្លៃ ក្នុងស្រុកល្វាឯម"
```

> ឈ្មោះទីតាំងខ្លីៗ (badge, hero, section title) ត្រូវបានដកចេញពី `address`
> ដោយស្វ័យប្រវត្តិ — ផ្នែកចុងក្រោយនៃអាសយដ្ឋាន (ឧ. «កណ្ដាល»)។

> បើដាក់ជាលេខទូរស័ព្ទ (`+855...`) Telegram មិនអាចបញ្ចូលសារជាមុនបានទេ
> ដូច្នេះគេហទំព័រនឹង **ចម្លងសារកម្មង់** ឱ្យស្រាប់ រួចបើកឆាត — គ្រាន់តែ paste ហើយ Send។
> ណែនាំឱ្យប្រើ **username** ដើម្បីឱ្យសារចូលស្រាប់។

## ៣. បន្ថែម / កែខោអាវ

កែឯកសារ `js/products.js` — បន្ថែមមួយ object ក្នុង `VITSTORE_PRODUCTS`៖

```js
{
  id: "linen-shirt",                  // ត្រូវតែមិនស្ទួន
  code: "VS-09",                      // លេខម៉ូដែល (បង្ហាញលើកាត)
  cat: "shirt",                       // shirt | pants | outer | acc
  name: "អាវក្រណាត់ Linen",
  en: "Linen Camp Shirt",
  price: 15.5,                        // តម្លៃជាដុល្លារ
  oldPrice: 19,                       // (ស្រេចចិត្ត) តម្លៃចាស់
  image: "assets/products/linen-shirt.jpg",
  badge: "ថ្មី",                        // (ស្រេចចិត្ត) ស្លាកលើកាត
  desc: "ការពិពណ៌នាខ្លីៗ…",
  material: "កប្បាស Linen ១០០%",
  sizes: ["S", "M", "L", "XL"],
  sizeGuide: { S: "ដងខ្លួន ១០៤ស.ម · បណ្ដោយ ៦៩ស.ម", M: "…" },  // (ស្រេចចិត្ត) តារាងទំហំ
  colors: [{ name: "ស", hex: "#e9e5dc" }, { name: "ខ្មៅ", hex: "#151514" }],
  details: ["ក្រណាត់ Linen ១០០%", "មានហោប៉ៅទ្រូង"],          // (ស្រេចចិត្ត) លម្អិត
  tags: ["រដូវក្ដៅ"],                                              // (ស្រេចចិត្ត) ជួយការស្វែងរក
  rating: 4.8, reviews: 19, sold: 88,                              // (ស្រេចចិត្ត) បង្ហាញលើកាត
  stock: 6
}
```

រូបភាពដាក់ក្នុង `assets/products/` (សូមប្រើទម្រង់បញ្ឈរ ៣:៤ ដើម្បីឱ្យកាតស្មើគ្នា)។
ដើម្បីបន្ថែមប្រភេទថ្មី កែ `VITSTORE_CATEGORIES` ក្នុងឯកសារដូចគ្នា។

## ៥. រចនាសម្ព័ន្ធ

```
index.html              ទំព័រទាំងមូល
css/styles.css          ស្ទីល (ពណ៌មាស-ខ្មៅ + serif បែប boutique)
js/config.js            ការកំណត់ហាង (Telegram, លេខទូរស័ព្ទ, អត្រាប្ដូរប្រាក់)
js/products.js          បញ្ជីខោអាវ + ឈុតណែនាំ
js/data.js              មតិអតិថិជន + សំណួរញឹកញាប់
js/app.js               មុខងារ៖ រនាំងអូស · ម៉ូដាល · កន្ត្រក · សារ Telegram
assets/store-bg.jpg     រូប background របស់ហាង (hero + about + contact)
assets/products/*.jpg   រូបខោអាវ
assets/fonts/           Kantumruy Pro + Cormorant Garamond (OFL)
```

## ៦. ការផ្សព្វផ្សាយ

គេហទំព័រនេះជា static — upload ទាំង folder ទៅ **Netlify / Vercel / Cloudflare Pages / GitHub Pages**
ក៏ដំណើរការភ្លាម ដោយមិនត្រូវការ server ឬ database។
